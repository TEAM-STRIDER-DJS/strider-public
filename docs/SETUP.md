# 설정 및 실행 검증

## 준비

- `.env.example`을 `.env`로 복사하고 자신의 서비스 설정을 입력합니다.
- Firebase 설정 파일과 앱 식별자를 맞춥니다.
- 소셜 로그인 플랫폼 등록과 사용할 백엔드를 준비합니다.
- 설치는 `npm ci`로 잠금 파일을 사용합니다.

## 로컬 확인

1. `npm run android` 또는 `npm run ios`로 네이티브 개발 빌드를 생성합니다.
2. 직접 만든 테스트 계정으로 일반·카카오·네이버 로그인을 확인합니다.
3. 피드 조회·등록, 이미지·영상 표시, 공유 링크와 채팅 연결을 확인합니다.
4. 푸시 토큰 등록과 수신을 자신의 Firebase 환경에서 확인합니다.
5. iOS에서 `HEALTH_SYNC_ENABLED=true`로 권한 요청·건강 데이터 동기화를 확인합니다. `DEMO_HEALTH_ENABLED`는 실제 서비스에서 끈 상태로 유지합니다.
6. 로그에 토큰·비밀번호·전화번호·메시지 본문이 출력되지 않는지 확인합니다.

## 검증 범위

구문 검사나 JavaScript 번들 생성은 네이티브 컴파일, 소셜 로그인, 푸시, 실제 백엔드 동작을 보장하지 않습니다. 실제 환경에서 위 항목을 별도로 확인해야 합니다.
